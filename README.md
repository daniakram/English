# منصة نماذج امتحانية — اللغة الإنكليزية
### إعداد الأستاذين: اكرم محفوض ✦ هاني محفوض

منصة امتحانات إلكترونية للشهادة الثانوية العامة (الفرع العلمي)، تعمل بالكامل من متصفح الطالب
دون أي خادم أو اشتراك شهري، وتُستضاف مجاناً على GitHub Pages.

---

## ١) التشغيل لأول مرة

1. ارفع محتويات هذا المجلد إلى المستودع **English** (الملفات في الجذر، لا داخل مجلد).
2. من المستودع: **Settings ← Pages ← Build and deployment**
   - Source: `Deploy from a branch`
   - Branch: `main` والمجلد `/ (root)` ثم **Save**.
3. بعد دقيقة يصبح الرابط جاهزاً:
   `https://<اسم-حسابك>.github.io/English/`
4. أرسل هذا الرابط لطلابك.

**كلمة سر لوحة التحكّم الافتراضية:** `Hani-Akram-2027`
غيّرها فوراً من: لوحة تحكّم الأستاذ ← تغيير كلمة السر (ستعطيك بصمة، الصقها في `index.html` مكان `adminHash`).

---

## ٢) كيف تشترك مع طالب

1. يرسل لك الطالب وصل الدفع أو يدفع نقداً.
2. افتح الموقع ← **لوحة تحكّم الأستاذ** ← **إضافة اشتراك**: الاسم، الموبايل، المدة (٣٠ يوماً مثلاً).
3. اضغط **أرسله عبر واتساب** — تفتح محادثة جاهزة بالرمز.
4. افتح تبويب **النشر إلى GitHub**، انسخ المحتوى، والصقه في ملف `data/subs.json` داخل المستودع ثم **Commit**.
5. خلال دقيقة يستطيع الطالب الدخول.

## ٣) كيف تجدّد لطالب

لوحة التحكّم ← الاشتراكات ← **+30** أو **+7** على سطر الطالب ← ثم **النشر إلى GitHub**.
**الرمز لا يتغيّر** — يمدَّد تاريخ انتهائه فقط، تماماً كما هو مطلوب.

## ٤) إيقاف طالب

زر **إيقاف** على سطره ثم النشر. يصبح الرمز معطّلاً فوراً.

## ٦) بنية الملفات

```
index.html        ← المنصة كاملة (الواجهة + النماذج + التصحيح)
data/subs.json    ← الاشتراكات (هذا الملف وحده يتغيّر يومياً)
.nojekyll         ← ضروري لعمل GitHub Pages بشكل صحيح
README.md
```

## ٧) إضافة نموذج جديد

في `index.html` ابحث عن `EXAMS.u2 = {...}` وأضف بعده `EXAMS.u3 = {...}` بالبنية نفسها.
كل سؤال يحتوي: `n` الرقم، `type` النوع (`mcq` / `short` / `open` / `essay`)،
`marks` الدرجة، `stem` نصّ السؤال، و`answer` أو `accept` أو `keys` للتصحيح الآلي.

## ٨) ملاحظتان مهمّتان

- **النتائج لا تُجمع مركزياً** في الاستضافة الثابتة؛ يرى الطالب نتيجته فوراً وترسل له صورتها.
  إذا أردت لوحة نتائج مركزية فهذا يحتاج خادماً صغيراً (خطوة لاحقة).

  الاسم والموبايل وتاريخ الانتهاء فقط.
